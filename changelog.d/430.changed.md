- Import makes a sound pair of banks: both run downstream (the way the centreline runs, or the way of the left bank), left and right are named looking downstream, banks that cross are refused, and two banks with no river polygon give one. `Session::import_downstream` takes a downstream point when there is no centreline (#430).
- The alignment default is unchanged for a river polygon the import built from two banks: with `use_water` unset, the rolling circle keeps to the water only for a polygon the user gave; `use_water: true` still uses a built one.
