- **The optimisation document.** `docs/optimisation/` sets out the mathematics and the approach of the weir search and the pool search for a river or waterway engineer: the problem, the chain of stages, the cut at one station, both searches, what is guaranteed and checked, what the cost does not know, and a planned method that is not built. One synthetic worked example runs through it, with its inputs, commands, numbers and figures in `docs/optimisation/example/`. The document is on the website (with its formulas as MathML, made at build time), and the README has a short section that links it. Tests hold it to the engine: the settings tables against the typed settings, every quoted number against the example, each guarantee against the test that pins it, and nightly re-runs of the example (`crates/owd-cli/tests/optimisation_doc.rs`). `CONTRIBUTING.md` has the rule: a change to the optimise or alignment code updates the document in the same pull request.
