- **A given design line.** `owd design-line DOC --line FILE --name NAME` adds a design line the user already has (from an earlier study, or drawn by hand) as an option with the method `given`. It gets the radius check of the other options; a line under the minimum radius is kept and reported, not refused. The volumes stage, the sections and the exports read it as any option; a new sizing checks it again and keeps it. The app shell adds one with `AppState::load_design_line`.
