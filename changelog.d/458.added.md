- **The proxy volume.** With no terrain, the plan cut can give a proxy volume: the plan area times a height the user states (`owd plan-cut --proxy-height-m M`, setting `proxy_height_m`). Each option's row gains `proxy_volume`, with its height, the volume by bank and a label that says it is a proxy, not a terrain volume. It takes none of the terrain volumes' names and is never added to one.
