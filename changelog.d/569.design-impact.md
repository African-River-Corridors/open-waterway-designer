- **The pool lattice's line changes only where a pool's line crossed itself or crossed the rest of the line.** A pool whose line is simple is searched and spliced exactly as before, so its line, cost and joins do not move (a test on the synthetic meander splices each pool's own line by hand and compares). A pool whose line crossed itself is now searched again on a moved end or keeps the baseline, so the joined line, its radius readings and the volumes measured along it move there, towards a line with no loop. The lattice option's checks gain `no_self_crossing`, and an option whose line still crosses itself is now marked failed (issue #569).
