- **No design number moves for an old file that needs no turn.** On the four new 0.4 fixtures (the web example's synthetic river, CEMT IV, PIANC WG 141 quality B, draught 2.5 m) the stored line, the pools, the weirs and the volumes are kept number for number, and `owd volumes` run again gives the stored dredge, dry cut, total and tallest face exactly. A turned file keeps every number and counts its chainages from the mouth: a weir's chainage is the baseline length less the old one, its pool level is the level on its other side and its lift changes sign; on the reversed fixture a new volumes run from the mouth gives the stored totals to within 0.0000001 m3. Chainages in the volumes' warnings are turned from whole metres, so each is within a metre. A kept 0.4 line now records its bends and cut-offs, where it recorded none.
