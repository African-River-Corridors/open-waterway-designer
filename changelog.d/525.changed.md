- **The reference line, the envelope sweep and the fits answer are typed stages (spec 0017, ticket 7).** The reference line is a pure function (`reference_line_stage`) stored as a stage record under `stages.reference_line`: its parameters as settings, its line and stretches as results (schema `schema/stages/reference_line.1.schema.json`), and as `depends_on` the hash of the input it read; a file that holds it as `inputs.reference_line` opens with it moved there, stale. The envelope sweep's answer is the typed `EnvelopeResult` (`schema/stages/envelope.1.schema.json`) and the fits answer the typed `FitsAnswer` (`schema/stages/fits.1.schema.json`), each checked against its type before it is stored; their `depends_on` is the hash of the typed `EnvelopeIn` and `FitsIn`. None has a hash of its own any more, so an answer stored before this change opens stale. Their numbers do not change. The fits record stays where it was, at the top level of the document.
