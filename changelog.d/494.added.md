- **The app can set the water-aware mode of the rolling circle.** Under Alignment, on the desktop app and the web app, a choice of Default (the setting unset: keep to the water when the design has a river polygon), Keep to the water, and Ignore the water sets the same setting as `owd align --use-water`, through the shell's `set_alignment_settings`. A change marks the alignment stale, and the run uses it. The panel shows the mode the last run used, as the option records it.
