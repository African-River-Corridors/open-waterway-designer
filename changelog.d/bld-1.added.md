- **Buildings, places and settlements as inputs (BLD-1).** A design can name a buildings file, a points of interest file and a settlements file (GeoJSON or GeoPackage, WGS84 or the project CRS): `owd import --buildings FILE --points-of-interest FILE --settlements FILE`, `inputs.buildings`, `inputs.points_of_interest` and `inputs.settlements` in `owd-project.json`, Open project, the Project panel's Load button, Load… and drag and drop in the web app. The design records each file by path, SHA-256, count and CRS, as it records the DEM, and never copies the features: a missing or changed file is said as for the DEM. Buildings below a confidence threshold (default 0.7) or a smallest area (default 0 m²) are counted apart, never dropped. Loading one leaves every stage fresh.
