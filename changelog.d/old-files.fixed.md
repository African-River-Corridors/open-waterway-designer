- **A design saved in format 0.4 opens up to date when it was up to date when saved.** Opening a 0.4 (or 0.3) file marked its alignment, optimise and volumes stages stale, so the volumes refused to run ("alignment is stale"), no long section or cross section could be drawn, and running the alignment again replaced a line that could not be made again. Now each stage whose stored hash matched the 0.4 formula when the file opens stays fresh, with its numbers; a stage that was stale stays stale. A file with only a pool-lattice line opens with that line as the fresh design line that the volumes, drawings, exports and reports read, and with both a rolling-circle line and a fresh lattice line, the volumes keep the lattice line's row. A kept line gets its bends and cut-offs, worked out from the stored line. `owd volumes` (and the app's Volumes run) then runs without touching the line and gives the stored totals again on the same DEM, now with stored stations for the drawings. The notes on open name the stages kept fresh and those left stale; the app now shows them with its other warnings.
