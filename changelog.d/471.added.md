- **The bank dataset file.** One GeoJSON file now carries the whole bank dataset: both banks, the river polygon, and what the source says (its accuracy and low-confidence stretches). `owd import --banks FILE` reads it in one go, through the same import as separate bank files; `owd export --banks FILE [--wgs84]` writes it. The app shell does the same (`AppState::load_bank_dataset`, `export_bank_dataset`). The form is described in `docs/bank-dataset-file.md`.
