- **The terrain memory limit can be raised.** On the command line, `--terrain-limit-gib GIB` (on any command) or `OWD_TERRAIN_LIMIT_GIB` raises the memory a terrain grid may take; the option wins over the variable. In the app, a "Terrain memory limit" field in the data panel does the same for the session. The limit is a setting of the machine and is never written to the design. A file over the limit is refused with a message that names the way to raise it on that surface. The default (6 GiB) does not change.
