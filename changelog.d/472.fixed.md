- **A large terrain file opens, inside a stated memory limit.** The GeoTIFF reader sets its own limit for the terrain grid (6 GiB on native targets, 1 GiB in the browser) instead of the `tiff` crate's 256 MiB default, so a terrain model of a long river loads on both surfaces. It decodes strip by strip or tile by tile into the grid, so the peak memory is about the grid. A file over the limit is refused before decoding, with its cell count, the memory it needs and the limit. Files that opened before give the same grid, bit for bit.
