- **The alignment case runner, `owd-cases`.** `owd-cases run [--cases DIR] [--report FILE]` plays each case's steps (new, import, size, align) through the command line and through the app shell, reads each expected value from both documents, and writes a JSON report with the gap per surface and a one-path check that the two documents are equal. Every expected value must name its source. The first case, a straight synthetic river, lives in `tests/alignment_cases/line-straight`; real cases are read from a folder the user names (`--cases` or `OWD_ALIGNMENT_CASES`).
