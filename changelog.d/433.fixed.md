- **The terrain rule in one place.** One function in `owd-format` (`stage_terrain`) answers which terrain file a stage call uses: the file the document names, when it is beside the document with the recorded hash, or the reason there is none. Every stage call in the command line and the app shell asks it. `owd align --method reroute` now follows the rule like `optimise` and `volumes`: with no `--dem` it uses the document's terrain, and it refuses a missing or changed file by name instead of asking for a DEM.
