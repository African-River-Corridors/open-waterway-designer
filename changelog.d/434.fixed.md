- **The depth table is read in the shell, not in the app's page.** One reader of `chainage_m,depth_m` text (`owd_format::design::bed::read_depth_table`) serves `owd bed --table` and the app. The app sends the depth and the table as typed; the shell refuses a bad line by its number and a depth that is not a number by quoting it, with the same words as the command line. The page no longer splits, converts or sorts the rows, so a table whose chainages go back is refused in the app too.
