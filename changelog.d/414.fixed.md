- **The web app says when its engine stops.** A worker that throws, traps (a wasm stack overflow is a trap), cannot be read or ends now fails every waiting call with "the web engine stopped: …", and a call made afterwards fails at once, where before a call could stay pending with no message. The text tells the user to reload; the design is kept. A unit test (`app/e2e/host.test.mjs`) drives the worker host with a stand-in worker.
