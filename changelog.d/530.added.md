- **Rates table and cost stage (spec 0017, ticket 12).** A design can hold a rates table (`inputs.rates`, schema `schema/stages/inputs.rates.1.schema.json`): dredge and dry cut per m³, disposal per m³ of all cut, and haul per m³ per km, each an amount and a currency, all in one currency, with the run's haul distance and, where given, haul distances for stretches of chainage (haul is summed station by station, so a stretch may start inside a reach). The cost stage (`cost`, schema `cost.1`) is a pure function: each rate times the volumes stage's stored volumes, by reach and in total, in that currency, with room on each figure for the output level it reaches (ticket 17). `owd cost` stores a rates table (`--rates FILE`) and prints the cost; it stores no cost yet. Refusals carry codes: `COST_NO_RATES`, `COST_RATE_MISSING` (a rate or a haul distance is never read as zero), `COST_MIXED_CURRENCY`, `COST_VOLUMES_STALE`, `COST_NO_VOLUMES`, `COST_HAUL_UNCOVERED`, `COST_VOLUMES_INCONSISTENT`, `COST_RATE_INVALID`. No design number moves: cost is new output.
