- **The web app keeps the DEM file, not its bytes (COG-1).** Load…, drag and drop and Open project give the worker the file itself; it reads the blocks it needs, so a large sectioned DEM opens at once with no long progress line. A DEM in strips that is too large to read whole is refused plainly, naming `owd dem prepare`. After a page reload a dropped file must be loaded again; Open project reads it again once the folder is allowed.
