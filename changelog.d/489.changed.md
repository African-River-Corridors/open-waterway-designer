- **One exit-code rule.** A command that saved the design now exits 0 even when an option fails a check (`owd align` with every method, `owd optimise`, `owd volumes`, `owd run`). The failed checks are printed on stderr as "the option fails: …", kept in the design, and listed as `failed_checks` in `--json` (per option for `volumes` and `run`). The new global flag `--strict` makes such a failed check exit code 1, after the save. **Scripts that relied on exit code 1 must add `--strict`.** Errors keep their codes; the README lists them in one table.
