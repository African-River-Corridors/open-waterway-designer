- **`--rule-set-file` works on every command, and a design sized with a Rule Set file runs its later stages.** The option is global: every command that opens a design loads the files, through one loader. A design that names a Rule Set that is neither built in nor loaded is refused with the set's id, version and content hash and "give its file with `--rule-set-file`", not "sizing is stale"; a loaded file whose hash differs from the one the design was sized with is refused with both hashes. The app shell keeps a loaded Rule Set file (`AppState::load_rule_set_text`) for every design it opens and gives the same refusals. Designs sized with built-in sets behave as before.
