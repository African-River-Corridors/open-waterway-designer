- **The app can load a Rule Set file.** "Load Rule Set file", under Rule Sets on the desktop app and the web app, reads a file and loads it for the session, as `owd --rule-set-file FILE` does. The picker then lists its set after the built-in ones, marked "from a file", and can size with it at once; a refused file shows the core's message and changes nothing. A design sized with a set that no one loaded says so under Rule Sets, in the core's words, with the control to use. The sizing choices of a session list its loaded sets (`Session::sizing_choices_for`, the shell's `sizing_choices`), and the shell's plan cut confirms the Rule Sets first, as every other stage does: before, it said the sizing was stale.
