- **A downstream point on both surfaces.** `owd import --downstream LON,LAT` and the app's downstream point run the banks towards the point and name them looking downstream, through the one import; each bank imported records the point in its provenance (`settings.downstream_lon_lat`). Banks that fail the side check at most stations (over `SIDE_WHOLESALE_SHARE`, 80 %) now get one plain message that they look named the wrong way round, in place of a line per station; `owd check-banks --json` keeps the list.
