- **The default rolling-circle line of a design with two banks and no given river polygon is now water-aware.** Before, a polygon the import built from the two banks left `use_water` off by default; now it is on, as for a polygon the user gave. The line moves to stay inside the river polygon and the option gains the `fits_in_water` and `feasible` checks. A design with a given polygon, or with a centreline alone, does not move. Set `use_water: false` (or `owd align --use-water false`) for the old line.
