- **Stage storage record and generated stage schemas (spec 0017, ticket 2).** A stage is read as a `StageRecord` (contract version, dependency hash, settings, output) through `Session::stage_record`, and the JSON Schema of each stage contract is generated from its Rust type into `schema/stages/<stage>.<version>.schema.json`. A test fails the build when a checked-in schema and its type differ. The document's keys and every result are unchanged.
