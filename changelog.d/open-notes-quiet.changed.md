- **The notes from opening an older-format design no longer read as errors.** The app showed every note as a yellow warning row, one per note. Now the notes that only inform fold into one quiet row ("Opened from an older format. Nothing was lost."), with Details to read them and Dismiss to remove the row. A note that asks you to act (a missing DEM, a stage to run again, a line that was not kept) stays a warning row, and each warning row has a Dismiss button. The rows clear when you open another design or press New. Each note now carries its kind (`info` or `action`) from the engine; the command line prints the same notes as before.
