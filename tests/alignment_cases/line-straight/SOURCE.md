# Straight river twin: where each value comes from

Synthetic geometry. No value here comes from a run of this tool.

## Banks
Two straight lines, 3,200 m long, 400 m apart, in EPSG:32630. Each has 33 positions, 100 m apart.
The river polygon is the rectangle between them.

## Required radius
The Rule Set gives a minimum bend radius of three vessel lengths. The vessel class is 85 m long.
3 × 85 = 255 m.

## Design line
A straight river has no bend to cut off. The design line is the centreline: 3,200 m. The rolling
circle may stop short of each end by a step, so the value is an outcome with a 1 % band.
